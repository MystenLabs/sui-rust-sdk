Expand description

Interface for signing user transactions and messages with a scheme that takes fresh randomness per signature

Randomized counterpart of SuiSigner. Today that is ML-DSA-65 only.

§Note

There is a blanket implementation of SuiRandomizedSigner for all T where T: [signature::RandomizedSigner]<[UserSignature]>, which handles the proper construction of the signing message.

The rng is taken as &mut dyn CryptoRngCore rather than &mut impl CryptoRngCore so that the trait stays dyn-compatible, like SuiSigner, and signers can be held as dyn SuiRandomizedSigner.
